## ساختار اجباری

1. **ایده / مسئله** — شکاف واقعی + شواهد فایل
2. **طراحی** — جریان، قرارداد، سطح حمله

4. **اجرا** — فایل‌ها و ترتیب
5. **تست / DoD** — واحد، قرارداد، e2e، معیار خروج
