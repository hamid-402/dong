# i18n

**تصمیم محصول (MVP):** رابط کاربری **فقط فارسی** است.

- رشته‌های UI در JSX فارسی‌اند.
- `apps/web/src/messages/fa.json` و `en.json` scaffold پنج‌خطی‌اند و **منبع حقیقت UI نیستند**.
- اگر انگلیسی وارد نقشه راه شد: اول صفحات auth (`login` / `register`) کامل استخراج می‌شوند، بعد بقیه.

این سند ادعای «i18n آماده» را محدود می‌کند تا با وضعیت واقعی هم‌خوان باشد.
