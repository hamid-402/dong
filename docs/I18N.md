# i18n

**تصمیم محصول (MVP):** رابط عملیاتی عمدتاً **فارسی** است؛ کاتالوگ `fa`/`en` برای سطوح auth و خطا منبع حقیقت است (R10-12 برش).

## وضعیت

| سطح | وضعیت |
|-----|--------|
| Auth (login / register / forgot) + 404/403 | کاتالوگ + `t()` |
| پرداخت به‌جای + برچسب‌های SLO پلتفرم + DSAR حساب | کاتالوگ + `t()` (عمق D3) |
| Shell / مالی باقی‌مانده | هنوز رشتهٔ درون‌خطی فارسی — استخراج تدریجی |
| ICU MessageFormat کامل | خارج از برش؛ فعلاً جایگزین `{name}` ساده |

## فایل‌ها

- `apps/web/src/messages/fa.json` · `en.json` — کلیدها باید یکسان باشند (`pnpm i18n:check`)
- `apps/web/src/lib/i18n.ts` — `t(key, locale?, vars?)`

## بعدی

1. استخراج nav/shell باقی‌مانده
2. locale switcher فقط وقتی en کامل برای مسیر کاربر آماده شد
3. ICU رسمی (مثلاً `@formatjs/icu-messageformat-parser`)
