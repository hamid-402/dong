# نقشه بازطراحی شل (هدر · مسیر · خانه · ابزار)

تاریخ: ۱۵ سپتامبر ۲۰۲۶

## هدف

هدر شلوغ و ناهمگون را جمع کنیم؛ مسیر فقط روی زیرصفحه و به‌جای هدر؛ خانه پر از مقاصد مفید (الگوی نسبت کاشی‌های ابزار).

## فاز ۱ — هدر فشرده

| مورد | قبل | بعد |
|------|-----|-----|
| جستجو | کادر پهن + متن + Ctrl K | فقط دکمهٔ آیکون ذره‌بین (همان پالت فرمان) |
| ثبت خرج دسکتاپ | دکمهٔ برجسته در هدر | حذف از هدر (FAB موبایل و مسیر مالی باقی است) |
| پروفایل | کپسول نام + اورب طلایی ناهمگون | دکمهٔ آیکونی هم‌سبک theme/bell (آواتار کوچک، بدون کپسول پهن) |
| تب‌ها / فاصله | شلوغ | فاصله و padding فشرده‌تر؛ active مثل chip ابزار |

## فاز ۲ — مسیر و بازگشت

| سطح | رفتار |
|-----|--------|
| صفحات اصلی تب | خانه `/w/:slug` · خرج‌ها · گروه/فضا · ابزار `/more` بدون `?intent=` · `/spaces` · `/account` | **بدون** نوار مسیر |
| زیرصفحه | بقیه (مثلاً `/settlements`، `/more?intent=`، تنظیمات، ادمین، …) | هدر اصلی **جایگزین** می‌شود با: بازگشت + خرده مسیر + ابزارهای فشرده (جستجو/تم/زنگ/پروفایل) — **نه** زیر هدر |

تابع: `isShellPrimaryPath(pathname, search)`.

## فاز ۳ — IA خانه ↔ ابزار

| سطح | محتوا |
|-----|--------|
| خانه | موزاییک غنی‌تر (variant نزدیک ابزار: مقاصد فضا + بلوک حساب)، نسبت/ارتفاع کاشی مثل گرید ابزار (زرد) |
| ابزار | پوشه‌ها + سنجاق + اخیراً + دریل‌داون intent؛ بدون تکرار بی‌هدف همهٔ خانه |

## فاز ۴ — نسبت کاشی

استایل compact ابزار (ارتفاع، padding، gap، ۳–۴ ستون) مبنا برای کاشی‌های خانه.

## ترتیب اجرا

1. هدر فشرده  
2. primary path + هدر جایگزین  
3. خانه غنی + نسبت کاشی  
4. تست breadcrumb + tsc

## یکپارچه‌سازی ناوبری ماژول (۱۵ سپتامبر → ارتقا دامنه)

نوارهای ops زیر عنوان (`OperationsModuleHeader`) بازنشسته شدند (no-op). سوییچ بخش‌ها از Shell / ابزارها / Palette است.

| سطح | قبل | بعد |
|------|-----|-----|
| خانه / ابزارها | گروه‌بندی نیت (تصمیم/ثبت/…) | ابزارها: ۵ دامنه؛ خانه: ماموریت سبک وضعیت‌محور |
| جست‌وجو | دامنهٔ سه‌تایی مسطح | همان ۵ دامنه |
| مالی | strip زیر عنوان | بدون strip؛ CTA عنوان + مسیر جدا |
| مرکز تأیید | آیتم داخل مالی | + badge هدر وقتی صف واقعی خالی نیست |
